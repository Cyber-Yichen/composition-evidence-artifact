# Data layout

- `shotbench/` contains the released metadata files `test.tsv`,
  `meta.parquet`, and `sc_labels.json`.
- ShotBench media are not redistributed. Obtain them from the official dataset
  release and place extracted images or videos under `data/shotbench/`.
- `shotqa/` is required only for fitting calibration statistics and training
  Channel B. Obtain it from the official ShotQA release.
- `cinetechbench/` is required only for the cross-benchmark experiment and is
  not redistributed.
- `cache/` stores content-hash-keyed detector JSON, depth arrays, and line
  segments generated by the extraction scripts.
